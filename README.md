# 📝 My Blog - Full Stack Blog Application

A simple and responsive full-stack Blog Application built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

The application allows users to register, log in securely, create blogs, view blogs, edit blogs, and delete blogs.

---

## 🚀 Features

- User Registration
- User Login
- Password Hashing using bcrypt
- JWT Authentication
- Protected Blog Operations
- Create Blog
- View All Blogs
- View Individual Blog
- Edit Blog
- Delete Blog
- Logout
- Responsive UI
- Mobile-Friendly Design
- MongoDB Database
- REST API using Express.js

---

## 🛠️ Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- CORS
- dotenv
